Lo que probablemente no funcionará en tu máquina (Windows)
chmod +x no aplica en NTFS: marcarlos como ejecutables solo es relevante si los lanzas desde Git Bash o WSL.
dev_up.sh usa curl: en PowerShell curl es un alias de Invoke-WebRequest, que no acepta -fsS → desde PowerShell el script no se ejecuta directamente. Pero Git Bash sí trae curl real.
Path con barras: bash las maneja bien, no hay problema.
Conclusión: para que dev_up.sh y dev_down.sh te sirvan en tu día a día tienes dos opciones:

Opción A — Usarlos desde Git Bash o WSL
# desde Git Bash
chmod +x scripts/dev_up.sh scripts/dev_down.sh
./scripts/dev_up.sh
./scripts/dev_down.sh
Opción B — En PowerShell, ejecutar Docker Compose directamente
Que es lo que ya estás haciendo en tu rutina:

docker compose -f docker/docker-compose.yml up -d
docker compose -f docker/docker-compose.yml down
Para el Paso 02 esto basta.
